# API Specification - OnePic Video\n\n## Base URL\n```\nhttp://localhost:5000/api\n```\n\n## Authentication\nCurrently using API keys in environment variables. Future: JWT tokens.\n\n---\n\n## Endpoints\n\n### 1. Upload & Analysis\n\n#### POST `/projects/:projectId/analyze`\nAnalyze uploaded product image using Claude Vision API.\n\n**Request:**\n```json\n{\n  \"imageBase64\": \"base64_encoded_image_data\"\n}\n```\n\n**Response:**\n```json\n{\n  \"projectId\": \"project_123\",\n  \"analysis\": {\n    \"productType\": \"cosmetics\",\n    \"brandName\": \"LuxeBeauty\",\n    \"colors\": [\"rose gold\", \"white\"],\n    \"features\": [\"premium\", \"luxury\"],\n    \"material\": \"glass\",\n    \"keyText\": [\"Premium Collection\"],\n    \"description\": \"High-end beauty serum\"\n  },\n  \"status\": \"success\"\n}\n```\n\n---\n\n### 2. Scene Generation\n\n#### POST `/scenes/generate`\nGenerate video scenes using OpenAI GPT-4.\n\n**Request:**\n```json\n{\n  \"analysis\": { /* product analysis */ },\n  \"projectSettings\": {\n    \"duration\": 30,\n    \"style\": \"cinematic\",\n    \"voiceStyle\": \"professional\"\n  }\n}\n```\n\n**Response:**\n```json\n{\n  \"scenes\": [\n    {\n      \"sequenceNumber\": 1,\n      \"type\": \"intro\",\n      \"description\": \"Logo close-up with elegant lighting\",\n      \"duration\": 3,\n      \"voiceScript\": \"Chào mừng...\",\n      \"cameraAngle\": \"macro\",\n      \"lighting\": \"studio\",\n      \"motion\": \"static\"\n    }\n  ],\n  \"backgroundMusic\": \"elegant piano\",\n  \"voiceStyle\": \"professional\",\n  \"status\": \"success\"\n}\n```\n\n---\n\n### 3. Video Generation\n\n#### POST `/video/generate`\nGenerate actual video scenes.\n\n**Request:**\n```json\n{\n  \"projectId\": \"project_123\",\n  \"scenes\": [ /* scene objects */ ],\n  \"aspectRatio\": \"9:16\"\n}\n```\n\n**Response:**\n```json\n{\n  \"projectId\": \"project_123\",\n  \"videoUrl\": \"https://storage.example.com/video_123.mp4\",\n  \"status\": \"generating\",\n  \"message\": \"Video generation started\"\n}\n```\n\n#### GET `/video/status/:jobId`\nCheck video generation progress.\n\n**Response:**\n```json\n{\n  \"jobId\": \"job_123\",\n  \"status\": \"processing\",\n  \"progress\": 45,\n  \"scenes\": [\n    {\n      \"id\": \"scene_1\",\n      \"status\": \"completed\",\n      \"videoUrl\": \"https://...\"\n    }\n  ]\n}\n```\n\n---\n\n### 4. Voice Over & Audio\n\n#### POST `/video/voice-over`\nGenerate voice-over using ElevenLabs.\n\n**Request:**\n```json\n{\n  \"voiceScript\": \"Vietnamese voice-over text\",\n  \"voiceStyle\": \"professional\"\n}\n```\n\n**Response:**\n```json\n{\n  \"audioUrl\": \"https://storage.example.com/voice_123.mp3\",\n  \"duration\": 28,\n  \"status\": \"success\"\n}\n```\n\n---\n\n### 5. Video Rendering\n\n#### POST `/video/render`\nRender final video with FFmpeg.\n\n**Request:**\n```json\n{\n  \"projectId\": \"project_123\",\n  \"sceneUrls\": [\"url1\", \"url2\"],\n  \"audioUrl\": \"https://...\",\n  \"aspectRatio\": \"9:16\",\n  \"quality\": \"high\"\n}\n```\n\n**Response:**\n```json\n{\n  \"projectId\": \"project_123\",\n  \"videoUrl\": \"https://storage.example.com/final_123.mp4\",\n  \"status\": \"completed\",\n  \"duration\": 30,\n  \"fileSize\": \"45MB\"\n}\n```\n\n---\n\n## Error Responses\n\n### 400 Bad Request\n```json\n{\n  \"error\": \"Invalid request\",\n  \"details\": \"Missing required field: imageBase64\"\n}\n```\n\n### 500 Internal Server Error\n```json\n{\n  \"error\": \"Failed to process request\",\n  \"details\": \"Error message details\"\n}\n```\n\n---\n\n## Rate Limiting\nCurrently unlimited (development).\nProduction: 100 requests/minute per IP.\n\n## CORS\nEnabled for all origins in development.\nProduction: Restrict to frontend domain.\n"
